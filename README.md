# Google Play Submission Checklist

A practical checklist for developers and teams preparing to submit an app to Google Play.

Use this checklist before submitting a new app or publishing a major update.

---

## App Information

* [ ] App name is finalized
* [ ] Short description is prepared
* [ ] Full description is reviewed
* [ ] App icon meets Google Play requirements
* [ ] Screenshots are prepared
* [ ] Screenshots accurately represent the app

---

## Privacy & Data

* [ ] Privacy Policy is available
* [ ] Privacy Policy URL works
* [ ] Data Safety information is completed
* [ ] Data collection is accurately declared
* [ ] Data sharing is accurately declared
* [ ] App behavior matches the submitted declarations

---

## App Functionality

* [ ] Production build has been tested
* [ ] Login process works correctly
* [ ] Test account is available if required
* [ ] Core features work as expected
* [ ] Requested permissions are necessary
* [ ] Sensitive permissions have been reviewed
* [ ] No major crashes or broken features exist

---

## Store Listing

* [ ] App category is correct
* [ ] Content rating questionnaire is completed
* [ ] Store listing metadata has been reviewed
* [ ] App icon is compliant
* [ ] Screenshots match the current version
* [ ] Store description accurately represents the app

---

## Final Review

* [ ] Test the production build
* [ ] Check privacy policy links
* [ ] Check all important URLs
* [ ] Review permissions
* [ ] Review Data Safety information
* [ ] Check for broken links
* [ ] Review Google Play policy compliance
* [ ] Confirm the submitted information matches the actual app

---
